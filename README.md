# בהרחבה · איגרות למנהל

איגרת שבועית של האגף לחינוך יסודי - בנים, רשת אהלי יוסף יצחק.

- כל איגרת יושבת בתיקייה משלה (למשל `toldot/`), עם `index.html`, תמונת שער `cover.png` ותיקיית `media/`.
- `index.html` בשורש הוא רשימת כל האיגרות.
- `tools/track.js` הוא המעקב השקט. הכתובת של דף הקליטה (Apps Script) נכתבת בו ב-`TRACK_URL`.
- האתר מתפרסם אוטומטית ב-Vercel עם כל שינוי בענף הראשי.
